`EditSharpApp.Instance.Commands.Run(...)` from C#, or its menu item or key. Generated by `--dump-commands`; don't edit by hand.

| `timeline.deleteClips` | Delete Clips |  | Removes clips. Args: `clips` (ids), `ripple` (close the gap, default false). |
| `timeline.duplicateClips` | Duplicate Clips |  | Copies clips straight after themselves. Args: `clips` (ids). Returns the copies' ids. |
| `timeline.move` | Move Clip |  | Moves a clip. Args: `clip` (id), `start` (seconds), `channel` (index of its kind, optional). |
| `timeline.place` | Place Media |  | Places a media on the timeline. Args: `media` (file path, must be in the project), `at` (seconds), `channel` (index, default 0), `video` (default true). Returns the new clips' ids. |
| `timeline.seek` | Move Playhead |  | Moves the playhead and the picture. Args: `at` (seconds). |
| `timeline.select` | Select Clips |  | Selects clips, replacing the selection. Args: `clips` (ids; empty clears it). |
| `timeline.splitAt` | Split Clips At |  | Cuts clips in two. Args: `at` (seconds), `clips` (ids; default every clip covering `at`). Returns the new clips' ids. |
| `timeline.trim` | Trim Clip |  | Trims a clip. Args: `clip` (id), `start` and/or `end` (seconds to move in; negative extends). |
